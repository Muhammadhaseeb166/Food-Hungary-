# Food-Hungary-
Foodie Hub is a modern and fully responsive fast-food restaurant website built using HTML, CSS, and JavaScript. The website is designed to showcase delicious food items like pizzas, burgers, fries, and drinks in an attractive and user-friendly layout.
It includes a stylish homepage, featured menu section, about section, customer reviews, and smooth interactive buttons for a better user experience. The design is fully responsive, making it suitable for mobile, tablet, and desktop devices.
This project focuses on front-end development skills, including layout design, styling, responsiveness, and basic JavaScript interactivity.
